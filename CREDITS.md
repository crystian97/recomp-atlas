# Fontes e atribuições

- Catálogo: [awesome-decomp-games](https://github.com/SubmitGame/awesome-decomp-games), dados disponibilizados sob CC0. O site usa seus dados e URLs de imagens, sem copiar sua interface.
- Capas de Ocarina of Time, Majora's Mask, Super Mario 64 e Star Fox 64: [Libretro — Nintendo 64](https://github.com/libretro-thumbnails/Nintendo_-_Nintendo_64).
- Capa de Mortal Kombat: Shaolin Monks: [Libretro — Xbox](https://github.com/libretro-thumbnails/Microsoft_-_Xbox).
- Tipografia: DM Sans e Space Grotesk, carregadas via Google Fonts.

As artes e marcas dos jogos pertencem a seus titulares. A licença dos dados não concede direitos sobre essas imagens. O Re:Play não é afiliado aos desenvolvedores ou fabricantes citados e não distribui os jogos.

A licença de distribuição do código próprio ainda deve ser escolhida pelo responsável do projeto. Nenhuma licença para o código é presumida a partir das licenças das fontes de dados.
